USC Discord Verification

USC Discord Verification is a service operated by ACM @ USC to verify access to an @usc.edu email address before granting members access to designated areas of the ACM @ USC Discord server.

How Verification Works

  1. Click the Verify Me! button in the ACM @ USC Discord server.
  2. Enter your @usc.edu email address.
  3. Receive a six-digit verification code by email.
  4. Enter the code in Discord.
  5. Receive the USC Verified role after successful verification.

Google API Usage

USC Discord Verification uses the Gmail API solely to send one-time verification codes from the ACM @ USC verification mailbox.

The application does not read, modify, or delete Gmail messages.

For more information about how data is handled, please read the USC Discord Verification Privacy Policy .

Questions about this service may be sent to usc.acm@gmail.com.

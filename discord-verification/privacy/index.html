USC Discord Verification Privacy Policy

Effective Date: September 3, 2026

USC Discord Verification is operated by ACM @ USC. This privacy policy explains how information is used when members verify an @usc.edu email address through the ACM @ USC Discord server.

Information We Process

When you use USC Discord Verification, the service may process:

  • Your Discord user ID.
  • The @usc.edu email address you submit for verification.
  • A one-time verification code.
  • Verification timestamps.
  • Information necessary to prevent duplicate or abusive verification attempts.

USC Discord Verification does not require access to your USC email account. You only need to receive an email at the address you provide.

Google API Data

USC Discord Verification uses the Gmail API and requests only permission to send email.

This permission is used solely to send one-time verification-code emails from the ACM @ USC verification mailbox.

USC Discord Verification does not use the Gmail API to read inbox messages, access email history, read contacts, modify messages, or delete messages.

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

How Verification Data Is Used

Verification information is used only to:

  • Send a one-time verification code to the submitted @usc.edu address.
  • Confirm that a Discord user has access to that email address.
  • Assign the USC Verified Discord role after successful verification.
  • Prevent duplicate verification.
  • Prevent abuse of the verification service.

Verification information is not used for advertising or marketing.

Data Storage

Plain-text @usc.edu email addresses are not retained in the verification database after processing.

The system stores a cryptographic keyed hash of the email address so duplicate verification can be detected without retaining the readable email address.

Pending verification records may include a Discord user ID, hashed email identifier, hashed verification code, expiration time, and verification-attempt count.

After successful verification, the service may retain the Discord user ID, hashed email identifier, and verification timestamp.

Data Sharing

ACM @ USC does not sell verification information.

Information is processed only through service providers necessary to operate the verification service, including Discord, Google, and Cloudflare.

Security

Verification requests are transmitted using encrypted HTTPS connections.

Sensitive application credentials are stored using protected Cloudflare Worker secrets. Verification codes and email identifiers stored in the database are protected using keyed cryptographic hashes.

Data Retention and Deletion

One-time verification codes expire after 10 minutes.

Pending verification records are removed after expiration or successful verification.

Successful verification records may be retained while necessary to maintain the integrity of the ACM @ USC Discord verification system and prevent duplicate verification.

Users may request deletion of their verification record by contacting ACM @ USC at uscacm@gmail.com.

Changes to This Policy

ACM @ USC may update this policy if the verification service or its data practices change.
